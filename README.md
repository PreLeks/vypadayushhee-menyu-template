# Выпадающее меню

Статический одностраничный шаблон интерфейса Pulse для творческой команды. Основной сценарий проекта — демонстрация профиля пользователя с выпадающей карточкой и адаптивной нео-бруталистской вёрстки.

## Возможности

- Навигация по разделам «Пространство», «Проекты» и «Команды».
- Открытие карточки пользователя по клику на профиль.
- Закрытие карточки кликом вне неё или клавишей `Escape`.
- Пункты пользовательского меню: профиль, уведомления, внешний вид, оплата и выход.
- Адаптивная компоновка для узких экранов.

## Технологии

- HTML5
- CSS3: Flexbox, media queries, локальные шрифты `Manrope`
- JavaScript (нативный DOM API)
- Локальные ресурсы: `fonts/*.woff2`, `img/avatar.png`
- Внешние зависимости, фреймворки, БД и API отсутствуют.

## Запуск

`package.json` в проекте отсутствует, поэтому установка зависимостей и сборка не требуются.

1. Откройте `index.html` в браузере.
2. Нажмите на профиль «Антон», чтобы открыть выпадающую карточку.

Для разработки можно запустить любой локальный статический сервер из корня проекта, например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

